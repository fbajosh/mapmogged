Layers

Instructions

  • Click Upload and choose one or more Google Timeline JSON files and/or manual CSV files
  • Each is interpreted as its own layer, so overlapping dates may exist
  • All processing is done locally on your computer - no information entered is communicated back to the server
  • You do not need to change the Google JSON file before uploading

  • Manual CSV files should include columns named lat, long, and time
  • Times are treated as UTC. Expected values for lat/long are decimals, and time is YYYY-MM-DDThh:mm:ssZ

  • Files process automatically after upload
  • Use the add icon in Layers to upload more files
  • You can adjust layer settings and reprocess after uploading
